# Third-party components

Sembrowse's direct-choice design is based on these MIT-licensed projects:

- [browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast), copyright its contributors.
- [TheoLeeCJ/SemIf-OpenJev](https://github.com/TheoLeeCJ/SemIf-OpenJev), copyright its contributors.

The release archives vendor the browser runtime from [ngxson/wllama](https://github.com/ngxson/wllama) at commit `23cf1f39fc9534fe81437200959b6dfc7106e45a`. Its license is distributed with the runtime at `extension/vendor/wllama/LICENCE`.

Model weights are not bundled or redistributed. The popup points only to pinned GGUF revisions chosen by the user.
